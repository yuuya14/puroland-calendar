# ピューロランド グリーティング通知

サンリオピューロランドのキャラクターグリーティング日程に、指定したキャラクター（マイスウィートピアノ・ウサハナ・ぼんぼんりぼん）が
掲載されたら、iPhoneのカレンダーに追加し、LINEで通知する仕組みです。

```
config.json         ← 通知するキャラクター・前日通知の時刻などの設定
piano_watch.py      ← 日程データを確認して、記録・カレンダー・通知文を作るスクリプト
data/appearances.json ← これまでに見つけた出演予定の記録（自動更新）
docs/greeting.ics   ← iPhoneで購読するカレンダー（自動更新）
docs/index.html     ← iPhoneでタップして登録するためのページ
.github/workflows/watch.yml ← 2時間おきに自動実行する設定
```

## 動き

- 日本時間 7時〜23時台に **2時間おき** に、公式スケジュールページが読み込んでいる日別データを今日から数週間先まで確認します
- 出演予定が **新しく掲載された・時間や部屋が変わった・掲載がなくなった** ときに、GitHub の Secret「LINE_TO」に登録した人だけに LINE で通知します
- カレンダーの予定には **前日20時の通知** が付きます
- データが取れなかったときは「⚠️ グリーティング日程の取得に失敗しました」の Issue が立ち、復旧すると自動で閉じます

## 通知を受け取る人を増やす

1. その人に LINE公式アカウントを友だち追加してもらう（LINE Developers の「Messaging API設定」タブのQRコード）
2. その人のユーザーID（`U` で始まる33文字）を調べる
   - LINE Developers コンソール →（プロバイダー）→「権限設定」からその人をメンバーに招待し、
     本人がログインしてチャネルの「チャネル基本設定」タブ下部の「あなたのユーザーID」を確認
3. GitHub の Settings → Secrets and variables → Actions → `LINE_TO` を編集し、カンマ区切りで追加
   （例: `U1111...,U2222...`）

友だち追加しただけの人（`LINE_TO` に入っていない人）には通知は届きません。
LINEの無料枠は「送信回数 × 送信先の人数」で月200通です。

## キャラクターを追加する

`config.json` の `characters` に追加します。`slug` はキャラクターページのURLの末尾です
（例: `https://www.puroland.jp/character/kuromi/` → `kuromi`）。

```json
{ "slug": "kuromi", "name": "クロミ", "emoji": "💜" }
```

## カレンダーのタイトルの先頭文字を変える

`config.json` の `"title_prefix": "🏰"` を書き換えます（空にすれば何も付きません）。

## 手動で今すぐ確認する

GitHub の Actions タブ →「Watch greeting」→「Run workflow」

「LINEにテストメッセージを送る」にチェックを入れて実行すると、`LINE_TO` に登録した全員にテストメッセージが届きます
（送信先を追加したときの確認用）。

## 注意

公式サイトが内部で使っているデータを読み取っているため、サイトの改修で動かなくなることがあります。
その場合は Issue で通知されます。
